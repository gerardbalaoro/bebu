# `bebu transactions`

Read history and edit expenses, income, and upcoming recurring payments

## Subcommands

- [`create`](transactions/create.md) - Create one-off or recurring expenses, income, and card
  refunds without automatic allocation
- [`delete`](transactions/delete.md) - Delete one occurrence or a verified recurring chain with
  atomic ledger reversal
- [`list`](transactions/list.md) - Read the complete history, including older records absent from
  the app cache
- [`operation`](transactions/operation.md) - Inspect a durable local transaction operation
- [`reclassify`](transactions/reclassify.md) - Move one completed expense to another category while
  preserving its stored fields
- [`recover`](transactions/recover.md) - Observe a saved transaction request without resending
  financial writes
- [`show`](transactions/show.md) - Read a complete transaction record
- [`update`](transactions/update.md) - Edit transaction amounts, details, dates, and upcoming
  recurrence rules
