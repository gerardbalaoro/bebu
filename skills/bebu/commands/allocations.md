# `bebu allocations`

Plan and save manual allocations, inspect history, or preview target funding

## Subcommands

- [`apply`](allocations/apply.md) - Apply one reviewed manual allocation plan atomically
- [`averages`](allocations/averages.md) - Read average allocation and spending from prior saved
  months
- [`history`](allocations/history.md) - Read native allocation history, optionally with matching
  transactions
- [`operation`](allocations/operation.md) - Inspect the original local allocation operation without
  sending writes
- [`preview`](allocations/preview.md) - Calculate target or restricted smart funding without
  changing the budget
- [`recover`](allocations/recover.md) - Observe the original allocation marker without resending
  uncertain work
- [`report`](allocations/report.md) - Summarize monthly allocations by category and nature
- [`set`](allocations/set.md) - Preview one absolute allocation or match its linked savings account
