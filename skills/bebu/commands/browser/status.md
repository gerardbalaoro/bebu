# `bebu browser status`

Show the running browser's CDP endpoint as JSON

## Usage

```
bebu browser status [options]
```

## Flags

| Flag           | Type    | Required | Description |
| -------------- | ------- | -------- | ----------- |
| `-h`, `--help` | boolean | No       | Show help   |
