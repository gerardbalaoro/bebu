# `bebu accounts`

Read accounts and change their configuration

## Subcommands

- [`list`](accounts/list.md) - List account IDs and balances in integer minor units
- [`show`](accounts/show.md) - Read a complete account record
- [`update`](accounts/update.md) - Change the account configuration. Use schema for the accepted
  JSON fields
