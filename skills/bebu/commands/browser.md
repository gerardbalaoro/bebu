# `bebu browser`

Run Patchright in the foreground and publish a local CDP endpoint

## Usage

```
bebu browser [options]
```

## Flags

| Flag                      | Type    | Required | Description                                                |
| ------------------------- | ------- | -------- | ---------------------------------------------------------- |
| `--headed`, `--no-headed` | boolean | No       | Show the browser window                                    |
| `-h`, `--help`            | boolean | No       | Show help                                                  |
| `--port`                  | number  | No       | Local CDP port; 0 chooses an available port `[default: 0]` |

## Supported syntax

report that the reference does not document it.
