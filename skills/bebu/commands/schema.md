# `bebu schema`

Show JSON schemas for write payloads

## Usage

```
bebu schema [options]
```

## Flags

| Flag                        | Type    | Required | Description                     |
| --------------------------- | ------- | -------- | ------------------------------- |
| `--compact`, `--no-compact` | boolean | No       | Return JSON without indentation |
| `-h`, `--help`              | boolean | No       | Show help                       |
