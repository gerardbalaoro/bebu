# `bebu targets`

Inspect, create, edit, or remove supported monthly spending targets

## Subcommands

- [`create`](targets/create.md) - Create a positive monthly spending target
- [`list`](targets/list.md) - Read target settings separately from category funds
- [`remove`](targets/remove.md) - Remove a monthly spending target without changing stored funding
- [`update`](targets/update.md) - Edit a positive monthly spending target
