# `bebu auth logout`

Delete local credentials and the separate bebu profile. Your Chrome profile stays intact

## Usage

```
bebu auth logout [options]
```

## Flags

| Flag           | Type    | Required | Description |
| -------------- | ------- | -------- | ----------- |
| `-h`, `--help` | boolean | No       | Show help   |
