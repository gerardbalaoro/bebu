# `bebu session prepare`

Prepare an encrypted session handoff without credentials in the output

## Usage

```
bebu session prepare [options]
```

## Flags

| Flag                        | Type    | Required | Description                               |
| --------------------------- | ------- | -------- | ----------------------------------------- |
| `--compact`, `--no-compact` | boolean | No       | Return JSON without indentation           |
| `-h`, `--help`              | boolean | No       | Show help                                 |
| `--out`                     | string  | No       | Write the browser expression to this file |
