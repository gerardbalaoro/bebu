# `bebu session`

Import authentication from a signed-in browser

## Subcommands

- [`import`](session/import.md) - Import one session source. Playwright state must include IndexedDB
- [`prepare`](session/prepare.md) - Prepare an encrypted session handoff without credentials in the
  output
- [`status`](session/status.md) - Show session expiry and budget IDs without credentials
